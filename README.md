## ✅ Task 2 — TaskFlow Lite (Interactive JavaScript Task Manager)

A fully functional task management application built using Vanilla JavaScript with browser-based data persistence.

### Features
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Task filtering system
- localStorage data persistence
- Dark/Light mode
- Input validation
- Responsive UI design
- Dynamic DOM rendering
- Event delegation

### Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript (ES6 Modules)
- localStorage API

### Concepts Implemented
- CRUD Operations
- DOM Manipulation
- Event Handling
- Event Delegation
- Modular Architecture
- Client-side Storage
- Form Validation

### Folder
```bash
Task-2-TaskFlow-Lite/
```
