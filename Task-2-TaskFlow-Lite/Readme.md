# TaskFlow Lite 🚀

TaskFlow Lite is a modern client-side task management application developed using Vanilla JavaScript.  
The application demonstrates CRUD operations, DOM manipulation, localStorage persistence, modular JavaScript architecture, and responsive UI/UX design principles.

This project was developed as part of the SoftNexis Web Development Internship Program.

---

# 📌 Features

## ✅ Task Management
- Add new tasks
- Delete existing tasks
- Mark tasks as completed
- Dynamic task rendering
- Task filtering system

## ✅ Filtering System
- All Tasks
- Active Tasks
- Completed Tasks

## ✅ Data Persistence
- Browser localStorage integration
- Tasks remain after page refresh

## ✅ UI/UX Features
- Responsive design
- Dark/Light mode
- Empty task state
- Real-time validation feedback
- Smooth user interaction

## ✅ JavaScript Concepts
- CRUD operations
- Event delegation
- DOM manipulation
- ES6 modules
- Array methods
- Form validation
- localStorage API
